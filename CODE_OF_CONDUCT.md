# Code of conduct

Short version: be decent to each other.

- Ask questions properly - assume the other person is trying to help.
- Critique the code and the ideas, not the person.
- No harassment, spam or pile-ons, in issues, pull requests or discussions.
- If something feels off, say so in the issue and a maintainer will step in.

This is a small project. The main rule is that it stays a pleasant place
to work on a document chatbot.
